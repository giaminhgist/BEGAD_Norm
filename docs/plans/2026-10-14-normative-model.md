# Learned Normative Gaze Modeling for BEGAD (CO/MCI/AD) — Implementation Plan

> **For the implementer:** REQUIRED workflow: use the `/minh-agent:code` entry to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the LNGModel learned normative-deviation pipeline (EXP-PROP-001, `mlp_deepset`)
to BEGAD_Norm and evaluate it under the existing baseline protocol (3 problems × 5-fold
participant CV × 20 seeds) for direct comparison with `outputs/baseline_balanced`.

**Architecture:** A new `src/begad_norm/normative/` package: per-participant matrices
(11 tasks × 25 features) with presence masks → encoder 25→128→128 → per-epoch CO latent
normative bank (per-task μ/σ over train-fold CO encodings) → learned comparator on
`[z, μ, z−μ, z·μ]` → 64-d per-task deviations → masked deepset pooling (mean‖max) →
128-d subject embedding → MLP head (sigmoid binary / softmax 3-class). AdamW, early
stopping on val AUC, best checkpoint = highest val AUC (earliest epoch wins ties), model
reseeded at the start of every fold.

**Tech Stack:** Python ≥ 3.12, PyTorch (CPU-only; new dependency, user-approved 2026-10-14),
numpy/pandas/scikit-learn/pyyaml (existing), uv, pytest.

**Spec:** this document — §1 Design spec, §2 Tasks.

## §1 Design spec

### 1.1 User-approved decisions (2026-10-14)

- Add `torch` (CPU build) to BEGAD_Norm via `uv add torch` — machine has no GPU (8 CPU cores).
- Scope: the main variant `mlp_deepset` only. Ablations (`mlp_mean`, `z_mean`, …) are out of scope.
- Stimuli = all 11 protocol tasks (comparable to the baseline's 275 columns). The 6-test-stimulus
  variant is left as a config option, not run now.

### 1.2 Protocol — must match the baseline exactly

- Problems (identical to `src/begad_norm/baseline/config.yaml`):
  - `co_vs_mci` — binary, positive = MCI;
  - `co_vs_ad` — binary, positive = AD;
  - `co_mci_ad` — 3-class (CO=0, MCI=1, AD=2): Sen/Precision/Spec/F1 are macro averages,
    AUC is macro one-vs-rest, Acc is overall accuracy.
- CV: participant-level stratified by group, 5 folds, generated by the SAME function as the
  baseline — import `stratified_folds` from `begad_norm.baseline.run_baselines`
  (permute within group with rng(seed), round-robin assignment). Do not re-implement.
- Seeds: the 20 baseline seeds
  `[42, 2026, 1, 0, 7, 123, 1234, 2024, 2025, 1337, 2, 3, 5, 10, 21, 777, 2020, 2021, 2022, 2023]`
  (locked in config.yaml).
- One sample per participant. Fixed threshold 0.5 (binary); argmax (3-class). No threshold
  tuning, no hyperparameter tuning.
- Metrics per evaluation: `acc, sen, precision, spec, auc, f1` — same definitions as the
  baseline's `metrics_binary` / `metrics_multiclass`.
- Detail CSV schema must equal `outputs/baseline_balanced/results/results_detail.csv`:
  `dataset, problem, model, seed, fold, n_train, n_test, acc, sen, precision, spec, auc, f1`.

### 1.3 Missingness and standardization (ported from LNGModel `src/data/tabular.py`)

- A (participant, task) row whose 25 features are ALL NaN is a missing task → masked
  everywhere (pooling, bank, losses). Ground truth for tests: `n_tasks_present` in
  `processed_dataset/metadata.csv` (BEGCO-029 and BEGMCI-019 are missing task 10).
- A NaN cell in an otherwise valid row is filled with the train-fold per-feature mean, so it
  contributes zero deviation after standardization.
- Standardization: per-feature mean/std computed over the train-fold subjects' valid rows only
  (unsupervised, leakage-safe); std clamped to EPS = 1e-6.
- The task mask is defined from all-NaN rows BEFORE anything else.

### 1.4 Model (ported from LNGModel `src/models/proposal.py`, locked hyperparameters)

| Component | Specification |
|---|---|
| encoder | Linear(25,128) → LayerNorm → GELU → Linear(128,128) |
| bank | buffers `bank_mu`, `bank_sigma` (11 × 128), refreshed EVERY epoch from train-fold CO encodings; per-task weighted μ/σ over valid CO rows; tasks with no CO coverage → μ=0, σ=EPS |
| comparator | `[z, μ, z−μ, z·μ]` (512-d) → Linear 256 → ReLU → Linear 128 → ReLU → Linear 64 |
| pooling | deepset: masked mean ‖ masked max → 128-d |
| head | Linear(128,64) → BatchNorm1d → ReLU → Dropout(0.3) → Linear(64, 1) sigmoid (binary) / Linear(64, 3) softmax (3-class) |
| optimizer | AdamW, lr 1e-3, weight_decay 1e-4 |
| schedule | max 150 epochs, patience 30 on val AUC, batch size 16, dropout 0.3 |
| loss | binary: BCELoss on sigmoid output; 3-class: CrossEntropyLoss on logits. Class weights = train-fold inverse class frequencies (matches baseline `class_weight: balanced`). |
| checkpoint | best = highest val AUC (earliest epoch wins ties); `best.pt`/`last.pt` include the bank buffers; restore must reproduce val predictions exactly |

### 1.5 Trainer behavior (ported from LNGModel `src/training/trainer.py`)

- `seed_all(cfg.seed)` BEFORE model construction; reseeded at the start of every fold so
  folds are independent of run order.
- `refresh_bank(train_ds)` called before each epoch (bank lags by one epoch; the best
  checkpoint contains exactly the bank its validation metrics were computed with).
- Epoch-end train/val metrics computed at `eval()` over ALL subjects of each split.
- Early stopping on val AUC (binary: ROC-AUC of positive class; 3-class: macro OVR AUC).
  NaN val AUC → abort the run with an explicit reason (never silently replace with 0.5).
- Artifacts per run dir: `metrics.jsonl`, `best.pt`, `last.pt`, `predictions.csv`,
  `summary.json`, `run_info.json` (git commit, code hash, data hashes, env, train/val ids,
  status).

### 1.6 Outputs

```
outputs/normative/
├── runs/{problem}/{model}/seed{s}/fold{f}/   # per-run artifacts (as §1.5)
├── results/results_detail.csv                # one row per evaluation (baseline schema)
├── results/summary.csv                       # via baseline aggregate_results.py
├── run_log.csv                               # job status, hashes, durations
└── provenance.json                           # config sha, data shas, env, git
```

Summary computed with the existing `begad_norm.baseline.aggregate_results`
(`--expected-rows 300 --per-group 100`), never re-implemented.

### 1.7 Run budget

3 problems × 5 folds × 20 seeds = 300 trainings. CPU-only, ~112 train subjects, ~7 batches/epoch,
≤150 epochs → estimated ~20–60 min wall with 8 workers (torch intra-op threads = 1 per worker).

## Global Constraints

- No GPU on this machine → CPU-only torch. `uv add torch` is authorized (user decision).
- Reuse the baseline's fold generation, seed list, and metric semantics verbatim — never copy
  with modifications.
- No threshold/hyperparameter tuning; no test set; all metrics are validation metrics.
- Determinism: identical seed → identical results (same fold assignment and model init).
- Do not modify `processed_dataset/`, baseline code, or existing baseline outputs. New code
  only under `src/begad_norm/normative/`, `tests/`, `docs/`.
- Generated markdown deliverables ship in English + Vietnamese.

## Review Focus

1. **Val-subject leakage** into the bank, imputation, or standardization — all statistics must
   be fitted on train-fold subjects only; the bank on train-fold CO only.
2. **All-NaN task rows** must be masked, never imputed as real observations.
3. **Single-class fold** (degenerate val set) → NaN AUC must abort loudly with its reason.
4. **3-class correctness** — probabilities sum to 1, argmax predictions, macro Sen/Spec/F1 and
   OVR macro AUC must match the baseline definitions.
5. **Checkpoint restore** must reproduce validation predictions exactly (bank buffers are part
   of the state dict).
6. **Binary positive class** must be the config's positive (MCI for `co_vs_mci`, AD for
   `co_vs_ad`) — sensitivity/specificity sign checked against the confusion matrix.
