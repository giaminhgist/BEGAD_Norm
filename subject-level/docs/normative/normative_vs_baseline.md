# Learned Normative Model vs Baseline — BEGAD CO/MCI/AD Classification

Comparison of the learned normative-deviation model (`normative_mlp_deepset`,
a port of LNGModel EXP-PROP-001) against the classical baselines in
`outputs/baseline_balanced`, under the SAME protocol: 3 problems × 5-fold
participant-level CV × 20 locked seeds = 100 evaluations per cell.
Vietnamese version: [normative_vs_baseline_vi.md](normative_vs_baseline_vi.md).

## 1. Method and protocol (identical for both sides)

- **Model (normative)**: encoder 25→128→128 per task → CO latent normative
  bank (per-task μ/σ over train-fold CO encodings, refreshed every epoch) →
  comparator on `[z, μ, z−μ, z·μ]` → 64-d per-task deviations → masked
  deepset pooling (mean‖max) → 128-d subject embedding → MLP head
  (sigmoid binary / softmax 3-class). AdamW lr 1e-3, wd 1e-4, batch 16,
  dropout 0.3, max 150 epochs, patience 30 on val AUC; best checkpoint =
  highest val AUC (earliest epoch wins ties).
- **Data**: one sample per participant, 25 features × 11 tasks; missing cells
  filled with the train-fold per-feature mean, standardized per fold on the
  training split; all-NaN tasks masked. Class imbalance handled with
  train-fold inverse-frequency loss weights (matches the baseline's
  `class_weight: balanced`).
- **Problems**: `co_vs_mci` (MCI positive), `co_vs_ad` (AD positive),
  `co_mci_ad` (3-class; Sen/Precision/Spec/F1 macro, AUC macro OVR).
- **Thresholds**: fixed 0.5 (binary), argmax (3-class). No threshold or
  hyperparameter tuning on either side.
- **Folds/seeds**: identical to the baseline — folds generated by the same
  `stratified_folds` function, the same 20 seeds
  `[42, 2026, 1, 0, 7, 123, 1234, 2024, 2025, 1337, 2, 3, 5, 10, 21, 777,
  2020, 2021, 2022, 2023]`.

Mean ± std over the 100 evaluations per (problem, model). ΔAUC = mean-of-means
difference vs the normative model (not a paired test).

## 3. Reading

- **co_vs_mci**: the normative model has the highest AUC (0.7674, +2.90 pp
  over svm_rbf) and the highest sensitivity (0.5838); its accuracy and
  specificity sit mid-table. On this problem the deviation-from-CO-norms
  signal is the strongest of the three.
- **co_vs_ad**: the normative model ranks 4th by AUC (0.8121), below
  svm_linear, logistic regression, and svm_rbf; its sensitivity (0.4208) is
  second only to GNB. With only 16 AD participants (3–4 per validation
  fold), every estimate on this problem is noisy — per-model AUC stds reach
  0.09–0.22 — and the fixed 0.5 threshold pushes most models toward
  all-negative predictions (qda: SEN 0.0000, SPEC 0.9985).
- **co_mci_ad**: the normative model is second by AUC (0.7392, −1.91 pp vs
  svm_rbf) with the best sensitivity (0.4922); svm_rbf leads on ACC/SPEC.
- No statistical significance tests were run; ΔAUC is a mean-of-means
  difference over 100 shared evaluations, and the model used ONE locked
  variant with ONE fixed threshold. These are development comparisons, not
  claims of superiority.

## 5. Limitations

- The 25 features were screened on the same cohort (uncorrected
  Kruskal–Wallis p < 0.1 in ≥ 3 tasks), so all reported numbers carry
  in-sample selection bias; no test set exists.
- co_vs_ad rests on 16 AD participants; per-fold validation sets contain
  3–4 AD subjects, so AUC/SEN/Spec are extremely noisy and the fixed 0.5
  threshold interacts strongly with the imbalance.
- Only the main variant (mlp_deepset) was run; the pooling/deviation
  ablations from LNGModel (mean/attention/max, hard z-deviation) were not.
- Validation metrics only; best checkpoint selected on validation AUC per
  fold (development rule, not an independent test).
- The normative bank uses only the train-fold CO subjects; instruction
  screens (tasks 0, 2, 6, 8, 10) are treated as stimuli like every other
  task, matching the baseline's 275-column layout.
