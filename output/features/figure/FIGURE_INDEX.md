## Caption

Per-figure caption: Distribution of {feature} ({unit}) by diagnostic group across the four tasks (KD1, KD2, KD3, READING). Box: median, IQR, whiskers at 1.5x IQR; points: individual participants (CN blue, MCI orange, AD green). Annotated p-values: two-sided Mann-Whitney U, asymptotic with tie and continuity correction, computed on the valid values shown in the panel; * p < 0.05. All p-values and valid group sizes were cross-checked against the published table in FEATURES_37_SUMMARY.md. Valid-n caveat applies to the nine features listed above.

## Cross-check against the published table

Every annotated p-value and per-group n was recomputed on the plotted values and compared with FEATURES_37_SUMMARY.md (396 p-cells, 132 n-cells; see `pvalue_crosscheck.csv`). Valid n: all 132 cells match. P-values: 379/396 cells match within the printed rounding; 17 cells differ slightly (max |diff| = 0.014) although the values, valid sets and the Mann-Whitney specification are identical. Cause: the published run tested raw machine-precision floats whose tie structure differs from the CSV values plotted here (tie-dense features such as A027/A046/D025/D030/A024, where near-equal values at the 1e-12 level change the tie correction). The figures annotate the p-values of the exact data shown.
