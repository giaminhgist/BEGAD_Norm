# Group comparison summary — all 72 features × 11 tasks (Kruskal–Wallis)

Exploratory summary of the Kruskal–Wallis group comparison (CO vs MCI vs AD) for
every feature in every task.

**Data**: `processed_dataset/features.csv` (1727 rows = 157 participants × 11
tasks; 2 all-NaN rows: `BEGCO-029` and `BEGMCI-019`, task 10) joined with
`processed_dataset/metadata.csv` (CO 100 / MCI 41 / AD 16).
**Statistics**: one Kruskal–Wallis test per (task, feature); 11 tasks × 72
features = 792 tests. `H` = Kruskal–Wallis statistic; `p` = uncorrected
p-value; `q_bh` = Benjamini–Hochberg q-value computed over all 792 tests.
Group means and n (participants with a valid value in that task) are shown per
group.
**Unit**: one feature value per (participant, task); within a task the three
groups are independent samples.
**Threshold**: p < 0.1 (uncorrected) is the screening threshold used for
feature selection; with 792 tests the results are exploratory and multiple
testing is expected.
